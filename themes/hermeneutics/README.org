Hermeneutics, a Hugo theme.

* Origin

The name comes from a song I really love. You can find the original video [[https://www.bilibili.com/video/BV18S4y1v7gV/][here]].

This theme doesn't have much to do with the religious or philosophical meaning of "hermeneutics", so you don't have to expect its style to match your first impression of the word.

* Features

- Sleek and clean (at least in my opinion).
- Lightweight (maybe).
- Fully responsive (maybe).
- Highly native (no NPM).
- Almost no JS.
- Good enough nice-to-haves:
  - Atom Feed & JSON Feed (how dare you brag about something so basic as if it were a feature?).
  - JS-free LaTeX support.
  - Simple image lightbox.
  - Git forge repo card support (GitHub/GitLab/Gitea/Forgejo).
  - GoatCounter (Doubleplusbased software, but the dashbord is too retro).
- Mainly written by human... wait, not human, to be precise, Element Musume.

* Progressive Enhancement

Progressive enhancement is a diversified and complex concept, and we will only talk about Javascript here.

Currently, Hermeneutics employs only three JS snippets:

- [[https://instant.page/][instantpage.js]]: Only speeds up loading and does not affect the loading process itself.
- Lightbox: You can click the image to open the original version under NoJS.
- Theme switching: It's a little tricky. But the result is satisfying to me: ~prefers-color-scheme~ still works and you can use the CSS checkbox to manually switch themes, though not persisted.

So yeah, 100% progressive enhancement in JS context. :3
